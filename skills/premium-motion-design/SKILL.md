# 静华 · Premium Motion Design

**静华** / Jìnghuá —— 高级感 + 华丽动画。

名字取自「静奢」与「华丽」:华丽要靠静来托。一句话的核心矛盾:

> **华丽不是加东西,是精确。**

绝大多数"想要华丽"的需求,最后做成廉价货,原因只有一个:把动效当成装饰往上堆。真正的奢华感来自**克制的数量 + 极致的精度**。这条规则统领下面所有内容。

## 0. 动手前先定级

拿到需求,先判断属于哪一档,不同档位规则不同:

| 档 | 特征 | 动效预算 |
|---|---|---|
| **静奢** | 品牌页、作品集、高端服务 | 每屏 1 个入场 + 1 个滚动节拍 |
| **动奢** | 产品发布、科技品牌、游戏 | 每屏 1 个入场 + 2 个节拍 + shader/3D 可用 |
| **静默** | 阅读为主、B2B、政务、教育 | 只做入场淡入,不做滚动特效 |

**默认走"静奢"。** 用户说"要华丽"时,先按静奢做,做完给他看,他觉得不够再往上加一档。反过来(先做满再减)永远减不干净。

## 1. 什么算高级

这四条是判断基准,缺一条就掉档:

**① 一个画面,一个焦点**
每屏只允许一个视觉重心。第二焦点出现时,不是"更丰富",是"更廉价"。

**② 留白是主体**
高级感来自敢于空。文字块四周的空间宽度 ≥ 相邻间距的 2 倍。宁可删内容,不要塞满。

**③ 动效服务于层级,不服务于炫耀**
每个动画都应该回答"这东西从哪来、到哪去"。如果回答不了,就是装饰,删掉。

**④ 材质真实**
阴影、玻璃、金属都要有物理依据(光从哪来、面朝哪)。做不到就别用,渐变凑出来的"质感"一眼假。

## 2. 什么算华丽(且不廉价)

华丽 = **编排感**,不是**数量**。

**必做的三件事:**

1. **入场编排 (stagger)** — 元素按阅读顺序依次进入,间隔 40–80ms。整体时长 400–700ms。这是"贵"的第一来源。
2. **缓动曲线** — 只用指数类减速:
   ```css
   /* 标准减速 */
   cubic-bezier(0.16, 1, 0.3, 1)   /* ease-out-expo */
   /* 稍快 */
   cubic-bezier(0.22, 1, 0.36, 1)  /* ease-out-quint */
   ```
   **绝不用** `bounce`、`elastic`、`spring`(除非模拟真实物理交互)。弹跳 = 早年安卓 = 廉价。
3. **滚动节拍 (scroll beat)** — 整页 1–2 个,不是每个区块都有。用 `transform` 和 `opacity`,不用 `top/left/width`。

**加分项(用对了很贵):**
- 视差只做 5–15% 位移,大了就晕
- 图片入场用 clip-path 揭示,比淡入有质感
- 数字滚动计数,配等宽字体防抖动
- 光标跟随的轻微磁性吸引,位移不超过 8px

## 3. 禁飞区:这 9 条一犯就廉价

来自 impeccable 检测器中判定为"AI 味"的规则,全部适用于"华丽"场景:

| 禁 | 为什么廉价 | 换成 |
|---|---|---|
| 弹跳/弹性缓动 | 过时、轻浮 | 指数减速 |
| 彩色发光阴影 | AI 生成 UI 的头号特征 | 中性 elevation 阴影 |
| 径向渐变光晕 | 同上,换成渐变画的版本 | 纯色或有意图的材质光 |
| 紫蓝渐变 | 最经典的 AI 配色 | 有意选定的单一强调色 |
| 奶油色/米色底 | "假装高级"的默认值 | 有依据的底色 |
| 渐变文字 | 装饰性,无意义 | 实色 |
| 自动滚动走马灯 | 抢注意力,内容看不全 | 用户驱动的轮播 |
| 呼吸/脉冲小圆点 | 假装"实时" | 静态指示器 |
| 卡片套卡片 | 视觉噪音 | 用间距和分隔线 |

**额外降级项:** 一根边上贴粗色条(最典型的 AI 卡片)、图标方块压在标题上方、大字号斜体衬线标题 —— 这仨都是"AI 创业落地页"模板。

## 4. 工作流:先挑毛病,再动手改

这是本 skill 的执行骨架。**永远先审后改**,不要边看边改。

### ① 挑毛病(taste 阶段)

逐项打分,不出结论先列事实:

```
[焦点]   每屏是否只有 1 个视觉重心?      → 屏 N 有 2 个,冲突
[留白]   文字块边距是否 ≥ 相邻间距 2 倍?   → 第 3 屏偏紧
[层级]   标题与正文尺寸比是否 ≥ 1.25 倍?   → 全站 1.18,偏平
[动效]   每个动画能否说出"从哪来"?         → 3 处说不出
[廉价]   是否命中第 3 节禁飞区?            → 命中 2 条
[精度]   边距、圆角、线宽是否统一?          → 圆角混用 8/12/16
```

如果有页面源码或 URL,用检测器跑一遍拿客观数据:

```bash
impeccable detect https://example.com          # 渲染后扫描
impeccable detect src/                          # 源码扫描
impeccable detect --json src/ > report.json     # 机器可读
```

**输出时必须给 P0–P3 分级:**

- **P0 阻断** — 廉价感源头、对比度不足、明显错位。必须改。
- **P1 重要** — 层级扁平、间距节奏乱。应该改。
- **P2 打磨** — 圆角混用、动效时长不统一。可以改。
- **P3 锦上添花** — 微交互细节。有空再说。

### ② 动手改(impeccable 阶段)

**一次只改一个问题,改完立刻验证。** 从 P0 开始,不要跳。

按问题类型选动作:

| 问题 | 动作 | 具体做法 |
|---|---|---|
| 太素、不敢放开 | **bolder** | 放大主标题层级差、加大留白、给强调色更高饱和度 |
| 太吵、堆得太满 | **quieter** | 删次要元素、降低动效数量、压缩配色到 2 色 |
| 层级扁平 | **typeset** | 建立 1.25× 以上的尺寸阶梯,重排字重 |
| 间距乱 | **layout** | 统一到 4/8 基准栅格,成组收紧、分段拉开 |
| 没情绪 | **delight** | 加入 1 处精心设计的微交互 |
| 缺华丽感 | **overdrive** | shader、滚动场景、3D,但遵守 4 上下文 WebGL 上限 |
| 收尾 | **polish** | 统一圆角、统一阴影、统一动效时长 |

### ③ 收工前的硬检查

- [ ] 每屏焦点唯一
- [ ] 未命中任何禁飞区规则
- [ ] 所有动效使用指数缓动
- [ ] 有 `prefers-reduced-motion` 降级
- [ ] 手机端动效降级(保留入场,砍滚动特效)
- [ ] 五个宽度目检:1440 / 1024 / 820 / 768 / 390
- [ ] `impeccable detect` 无 P0 遗留

## 5. 反模式:三种最常见的翻车

**① 动效太多 = 没有动效**
整页都在动,读者眼睛无处停。每屏留一处"静",动效才有存在感。

**② 时长太长 = 卡顿**
入场超过 800ms 就让人等。单元素 400–700ms,总编排不超过 1.2s。

**③ 什么都要发光 = 什么都不亮**
发光只在暗背景上、只在 1 个元素上有意义。全站都发光 = 没有光。

## 6. 与其他 skill 的关系

- **taste-skill** — 提供版式库和"从零建页"的模具,它的五尺寸浏览器验收可直接复用。
- **impeccable** — 提供本节第 3 节的禁飞区规则和检测器,以及第 ② 步的修改动作词汇。
- **本 skill** — 定义"什么时候用哪一个"以及"高级感和华丽如何共存"。这是它们都没回答的问题。

## 7. 快速自检清单

交付前逐条过:

```
□ 定级了吗?(静奢 / 动奢 / 静默)
□ 每屏一个焦点?
□ 留白够不够狠?
□ 动效都能说出"从哪来"?
□ 缓动全是指数曲线?
□ 禁飞区零命中?
□ reduced-motion 降级做了?
□ 手机端跑过了?
□ 检测器零 P0?
```
